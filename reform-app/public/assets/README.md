# 画像アセット置き場

契約書・見積書で使うサンプル画像を置くディレクトリです。

## company-seal.png(未配置)

請負者(自社)の印鑑画像のサンプル。**まだ配置されていません。**

チャットに貼られた画像は会話内の画像として渡されるため、ファイルとして取り込めませんでした。
以下のいずれかの方法で配置してください。

1. **アプリから登録する(推奨・実装済み)**
   アプリの「会社情報」画面 → 「印鑑画像をアップロード」から選択すると、
   長辺400pxに自動縮小して端末内(localStorage)に保存され、
   見積書・契約書に自動で表示されます。リポジトリへの配置は不要です。

2. **リポジトリに既定画像として置く**
   `company-seal.png` という名前でこのディレクトリに置いてください。
   (アプリ側で既定値として読み込む対応は未実装です。必要なら実装します)

推奨: 背景が白または透過のPNG。正方形に近いもの。
